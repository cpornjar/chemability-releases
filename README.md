# Chemability — downloads

Free chemistry drawing for teaching: structures, reactions, curved-arrow mechanisms, TLC plates and
glassware, with teaching aids that explain what is wrong and why. ChemDraw shortcuts, CDXML in and out.

- **Use it in the browser or on iPad:** https://chemability.vercel.app
- **Download for Mac (Apple silicon):** [latest release](https://github.com/cpornjar/chemability-releases/releases/latest)
- **First-open guide and examples:** https://chemability.vercel.app/download/

This repository only holds the installers. Each release's notes list what changed.

## Opening the Mac app the first time

During the pilot the app is not yet registered with Apple, so macOS warns on first open:

1. Drag Chemability into Applications and open it. When macOS says it can't verify the developer, choose **Done**.
2. Open **System Settings ▸ Privacy & Security**, scroll down, click **Open Anyway** next to Chemability.
3. From then on it opens normally.
